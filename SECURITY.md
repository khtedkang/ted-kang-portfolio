# Security and Privacy

This repository is a presentation layer and does not require secrets, environment variables, authentication, databases, analytics, or form processing.

Please report a suspected disclosure of confidential or personal information privately to `khted.kang@gmail.com`. Do not open a public issue containing the sensitive material.

The site links to email, LinkedIn, GitHub, and a local resume file. It does not collect visitor information. Before any public release, review the repository history as well as the current files for credentials, private paths, restricted company material, and unintended personal information.
